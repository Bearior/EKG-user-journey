# รับ ECG ให้กรอกน้อยลง

ปรับตามรีวิวหน้ารับ ECG: ผู้ใช้บนรถฉุกเฉินต้องการเริ่มเคสเร็วและลดการพิมพ์

## Journey ที่ปรับ

1. เปิดหน้ารับ ECG: มีรหัสสังเคราะห์ `DEMO-...` ให้อัตโนมัติ ไม่ต้องพิมพ์ หากต้องการเปลี่ยนกดสร้างรหัสใหม่ครั้งเดียว
2. กดไมค์ พูดอาการสมมติภาษาไทย เห็นสถานะฟังและข้อความที่กำลังถอดเสียง
3. กดหยุด รอผลสุดท้าย ตรวจ/แก้ข้อความ แล้วเริ่มเคส ช่องอาการไม่บังคับกรอกหากต้องการเริ่มจาก ECG ก่อน
4. ยืนยัน ECG แล้วส่งปรึกษาได้ทันทีโดยไม่ต้องรอ AI คงขั้นตอนยืนยันเคสก่อนส่งเพื่อไม่ส่งผิดเคส

รหัสใช้ crypto.randomUUID ตัดเป็น 24 ตัวอักษร hexadecimal พร้อม DEMO- หาก browser ไม่มี randomUUID ใช้ getRandomValues; หากไม่มี Web Crypto ใช้เวลาและลำดับภายในหน้าเว็บสำหรับเดโมเท่านั้น ไม่ใช่ HN หรือรหัสหน่วย EMS ไม่ใช่การจอง ID กับ backend และไม่รับรอง uniqueness ข้ามอุปกรณ์ ระบบจริงต้องจัดการ uniqueness/idempotency ที่ server เพิ่ม

## Speech-to-text

- ใช้ browser Web Speech API ภาษา `th-TH` เปิดแบบ continuous และ interim results
- ข้อความ final เติมต่อท้ายข้อความก่อนเริ่มฟัง และคำนวณจาก result list ของ session เพื่อไม่เติมผลเดิมซ้ำ
- ข้อความ interim แสดงเป็น preview ยังไม่ใช้เป็นอาการของเคสจนบริการให้ final
- ระหว่างฟังล็อก textarea กับปุ่มเริ่มเคส; ปุ่มหยุดรอผลสุดท้ายก่อนปลดล็อก
- เปลี่ยนหน้า/เริ่มเคสใหม่ยกเลิก session และละทิ้ง callbacks ที่มาช้า ไม่ให้เขียนข้ามเคส
- กรณี browser ไม่รองรับ ไม่อนุญาตไมค์ เครือข่ายบริการขัดข้อง หรือไม่พบเสียง มีข้อความให้พิมพ์เองและ retry ได้
- ไม่เริ่มฟังเมื่อโหลดหน้า เริ่มเมื่อผู้ใช้กดไมค์เท่านั้น

Browser อาจส่งเสียงให้บริการภายนอกและไม่รองรับ offline ดู [MDN](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition) จึงระบุบนหน้าจอให้ใช้ข้อมูลสมมติ แอปไม่เก็บ audio blob แต่ไม่รับรองว่าส่งเสียงประมวลผลในเครื่องทั้งหมด ก่อนใช้จริงต้องตกลงบริการ speech และการจัดการข้อมูลกับโรงพยาบาล

## Validation

Tests ครอบคลุมรหัสไม่ซ้ำใน 100 ครั้งและผ่านรูปแบบ DEMO, Thai settings, append ไม่ซ้ำ, interim/final, stop/end, denied permission, unsupported browser, cancel/late callbacks, 400-character limit และ start failure ใช้ recognition จำลอง; ยังไม่ได้ตรวจด้วยไมค์จริงหรือรับรองความแม่นยำในรถที่มีเสียงรบกวน
