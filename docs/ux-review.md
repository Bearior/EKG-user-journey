# UX review จากการกดใช้งานใน Chrome

วันที่ 6 ตุลาคม 2026 ตรวจต้นแบบที่ http://127.0.0.1:4174 ด้วยข้อมูลสาธิตในแท็บแยก ไม่แก้ข้อมูลที่ผู้ใช้กรอกในแท็บเดิม

## ปัญหาที่เห็นจริงและการแก้

| ก่อนแก้ | หลังแก้ |
| --- | --- |
| ส่งปรึกษาแล้วค้างหน้าตรวจ ไม่ชัดว่าจะกดดูผลหรือเปิดแพทย์ต่อ | ส่งสำเร็จแล้วพาไปติดตามผลอัตโนมัติ; offline ยังอยู่หน้าส่งและบอกให้ retry |
| แพทย์ตอบแล้วค้างมุมมองแพทย์ | กลับหน้าติดตามผลพร้อมคำตอบและสถานะ |
| แพทย์ถูกนับเป็นขั้นตอนที่ 4 ของคนหน้างาน | 3 ขั้นตอนของทีมหน้างาน + ปุ่มสลับบทบาทสำหรับผู้สาธิตแยกส่วน |
| กลับหน้าแรกแล้วปุ่มหลักเริ่มเคสใหม่และล้างเคสเดิม | ปุ่มกลับเคสปัจจุบันเด่น; เริ่มเคสใหม่อยู่ในส่วนพับแยกและถามก่อนล้าง |
| AI ไม่ตอบจนผู้ใช้กดจำลองให้เสร็จ | AI mock ตอบอัตโนมัติประมาณ 2 วินาที; ส่งปรึกษาไม่ต้องรอผล |
| JSON/เครื่องมือเดโมปะปนกับปุ่มงานหลัก | เครื่องมือผู้สาธิตอยู่ในส่วนพับ |
| ผล AI/คำตอบอยู่ใต้กราฟที่กินพื้นที่มากบนมือถือ | หน้าติดตามผลแสดง AI และความเห็นแพทย์ก่อนกราฟ; หน้าแพทย์ยังให้ ECG มาก่อนอ่าน |
| กราฟทำให้ grid มือถือขยายและทั้งหน้าล้นแนวนอน | grid ใช้ minmax(0,1fr) และ children min-width:0; เลื่อนเฉพาะกราฟ |
| เริ่มเคสใหม่ใช้ draft ที่มีรหัสเคสเดิม | สร้าง draft รหัสใหม่และอาการว่างหลังเริ่มเคส; ปฏิเสธเคสใหม่ที่รหัสเท่าปัจจุบัน |
| หน้าใหม่รักษาตำแหน่ง scroll เดิม ทำให้ไม่เห็นบริบท | เปลี่ยนหน้าแล้วกลับด้านบน; การอัปเดต AI รักษา focus และข้อความ draft |

## ผลตรวจด้วย browser

- เริ่มเคส → ยืนยัน ECG → ส่งปรึกษา → หน้าติดตามผล: ผ่าน
- AI mock ตอบเองโดยไม่กดเครื่องมือผู้สาธิต: ผ่าน
- สลับแพทย์ → กรอกความเห็น/คำตอบ → กลับติดตามผลพร้อมคำตอบ: ผ่าน
- AI วิเคราะห์ไม่ได้ + เครือข่ายจำลองขาด → ขึ้นส่งไม่สำเร็จ → เปิดเครือข่าย → retry → แพทย์ตอบได้: ผ่าน
- โหมดอ่านอิสระ: ผล AI ยังซ่อนก่อนแพทย์ส่งความเห็น และเปิดเผยหลังส่ง: ผ่าน
- กลับเริ่มเคสแล้วทำเคสเดิมต่อได้; รหัสใน draft เคสใหม่ต่างจากเคสปัจจุบัน: ผ่าน
- จอมือถือ viewport 390 × 844: หลังแก้ document scrollWidth 375 px ภายใน viewport 390 px ไม่ล้นทั้งหน้า (มีพื้นที่ scrollbar); กราฟยังมี scroll ภายใน
- ตรวจภาพ desktop และ mobile; เก็บภาพใน output/qa ซึ่งไม่เข้า Git
- Unit/model/API/dictation tests 21 กรณี และ syntax check ผ่าน

## ขอบเขตการยืนยัน

การตรวจนี้ยืนยัน interaction ของต้นแบบและ visual layout ใน Chrome ไม่ใช่ผล usability study กับเจ้าหน้าที่บนรถหรือแพทย์จริง ไม่ได้ทดสอบไมค์/ความแม่นยำการถอดเสียงครั้งนี้ และไม่ได้เชื่อม ECG device, inference service หรือแพทย์จริง

ประเด็นที่ควรให้แพทย์และ EMS รีวิวต่อ: ข้อมูลขั้นต่ำก่อนส่ง, วิธีรับปรึกษาในงานจริง, ข้อความผล AI, ความจำเป็นของการเทียบ serial ECG และสภาพการใช้มือ/เสียงบนรถ
